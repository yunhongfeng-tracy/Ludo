# Ludo 阶段一验收记录

日期：2026年09月07日  
版本：0.1，基础体验版  
结论：基础可玩版通过本轮验收。高级、终极和四档强度证明不属于本轮完成范围。按用户最新要求，当前以电脑浏览器为交付重点，手机适配暂缓。

## 交付内容

项目根目录的 `index.html` 是独立运行的成品，HTML、CSS、JavaScript 和棋盘图形均已内嵌，不需要 Node、服务端或 AI API。开发预览服务只用于本机预览，游戏文件不依赖该服务。

源码保留在 `src/`，构建工具在 `tools/`，测试在 `tests/`。已开放初级和中级，支持随机先手、真实随机骰子、合法走法提示、移动动画、吃子、到家、终局、重开确认、玩法说明和音效开关。对局不自动保存。

## 本轮发现及修复

1. 页面恢复时可能卡在掷骰或走棋动画。现将已提交动作的收尾保存为一次性操作，页面恢复后补全展示、统计及调度，重开时清除旧收尾。
2. 调整了桌面棋盘与操作区的宽度关系，棋盘标题和图例与棋盘边缘对齐。
3. 窄屏验证期间发现固定操作区受父级入场变换影响，已经修复并检查视口边界。该项属于固定定位受变换影响的问题。用户随后要求暂缓手机适配，后续停止扩展这部分范围。
4. 浏览器验收工具默认禁用本地文件导航。已使用工具支持的本地文件配置完成真正的 `file://` 断网测试，游戏文件自身无需该配置。

## 覆盖边界

- 冒烟和少量浏览器对局不能证明四档难度差异，本轮不宣称策略最优。
- 高级、终极、Worker、正式留出集强度检验、浏览器性能预算将在后续阶段实现和验证。
- Edge、Firefox、Safari 尚未单独实测；已有窄视口检查不等同于手机真机验证，手机适配暂缓。
- 页面恢复目前验证了合成生命周期事件，尚未覆盖所有浏览器真实 BFCache 行为。
- 音效已提供，尚未进行人工听感验收。
