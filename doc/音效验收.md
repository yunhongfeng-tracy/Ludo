# 骰子、棋子音效与安全星标验收

日期：2026年09月09日

版本：0.5.8

## 修改内容

- 掷骰采用连续碰撞与落桌声，长度跟随真实骰子动画；棋子每落一格播放短木敲声，玩家和电脑均适用。
- 减少动画模式下，一次走棋仅在最终落点播放一声，避免多格声音瞬间叠加。
- 默认允许音效，在用户点击开始对局时解锁浏览器音频。右上角扬声器显示真实状态，可立即静音；本地存储记住选择，存储受限时仍保留本次设置。
- 静音、重开、进入后台、查看更新页或打开规则时停止声音；隐藏的游戏不会继续发声。
- 音效在浏览器本地合成，无外部音源和网络请求，独立随机源不影响真实骰点。
- 浏览器不支持音频、创建音频失败或播放节点失败时，游戏继续正常运行。
- 校准桌面底图的四个错位星标，并在四个起点补上星标。八个标记均从引擎的安全格集合生成，与棋子共用坐标层；小屏保留同规则的 SVG 棋盘。
- 旧星通过局部纸纹图层覆盖，底图文件、箭头、格线和吃子规则保持原样。

## 验证结果

- 构建、JavaScript 语法、UTF-8、单文件离线资源和 Git 空白检查通过。
- 原生 Chromium 的 OfflineAudioContext 渲染确认全部音效非空，无非法数值或削波。50 次重叠触发压力峰值小于 1；静音为全零；播放结束后节点全部释放。
- 实际浏览器对局覆盖玩家和电脑的掷骰与逐格移动，检测到非零音频输出。走棋音次数与实际移动格数一致，具体采样次数见浏览器报告。
- 最终成品实际采样 16 次掷骰、9 段移动和 21 个逐格声。音频上下文挂起后延迟 300ms 恢复，仅播放当前骰子动画的剩余声音；延迟 800ms 超出动画后不补播。恢复前静音或重开均不补播旧动作，重新开启音效可检测到预览声。
- 静音 40ms 后活动声源为零，220ms 后检测为静音，后续掷骰不创建新声源。刷新后的静音偏好恢复正常。
- 重开、合成隐藏事件和真实打开更新页均停止声音。隐藏事件的合成检查不等同于全部操作系统后台行为覆盖。
- 减少动画模式的 6 段移动均每次只发一声。
- 不支持音频、构造音频上下文失败、音频节点创建失败的浏览器场景均能继续实际走棋，0 页面脚本错误。
- 原有骰子时序测试通过，覆盖玩家和电脑的 500ms、1200ms、减少动画模式，以及合成页面恢复和动画中重开，未提前公布骰点。
- 桌面截图确认扬声器开关可见，开关更新不改变右侧面板布局。
- 181 项规则与 AI 自动测试全部通过，另核验双方 100 个同格落子案例，16 个安全格共存和 84 个普通格吃子均符合当前规则。
- 右侧面板状态切换回归通过，包含桌面与手机的重开入口、长文案及真实骰子动画。
- 1536px、1280px、390px 视口开局前后均恰好显示八个安全星标，屏幕星心与规则格心一致。每种视口均实际点击红子出营并继续移动，覆盖层未遮挡棋子输入，页面脚本错误为零。
