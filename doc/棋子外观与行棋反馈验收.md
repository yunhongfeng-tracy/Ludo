# 棋子外观与行棋反馈验收

日期：2026年09月09日

版本：0.5.9

## 修改内容

- 开局前后、重新开始始终使用无棋子底图与同一套真实木纹棋子。等待开局时棋子仍不可操作。
- 每一步结束后，标出起点、落点和最后移动的棋子，棋盘下方保留结果说明，下一次掷骰不会清掉这条说明。
- 安全格共存显示双方棋子编号和保护原因，出营、普通移动、吃子和到家也说明具体棋子。
- 被吃棋子通过短暂飞行动画回到各自基地，音效播放一次；减少动画模式直接显示最终结果。
- 回营过程中真实棋子在基地隐藏就位，避免动画副本消失后触发第二次飞行。重开、页面隐藏和恢复不会留下副本或重复结算。
- 手机取消侧栏的入场位移动画，避免该动画改变固定操作栏的定位范围，确保掷骰按钮留在屏幕底部；操作栏采用不透明纸面，避免下方文字透出。

## 验证结果

- 构建、JavaScript 语法、UTF-8、离线资源与 Git 空白检查通过。
- 181 项规则与 AI 测试通过，棋规、真实骰点和策略未变。
- 15 组浏览器交互验收覆盖真实开局外观、普通移动、双方安全格共存、到家、电脑移动、双方吃子、多子回营、重开、更新页、页面恢复、手机尺寸与减少动画模式。
- 回营动画关键帧的终点与各棋子的真实基地中心一致，移除动画副本后没有位置跳变。吃子、日志、奖励和音效均只结算一次。
- 桌面和手机尺寸的开局前后，八枚棋子的相对位置、尺寸、纹理和棋盘背景一致。长结果文本在固定高度内完整显示，右侧面板尺寸不变。
- 原有右侧面板与骰子时序回归通过；真实音频对局、静音、恢复和失败降级回归通过。
