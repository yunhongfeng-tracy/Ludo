## 后续更新

1. 修改源码与 `src/releases.json`，同步 `package.json` 版本，运行 `npm run build` 与 `npm run check`。涉及棋规或策略变更时再运行相应测试。
2. 通过项目对应的「连接 tracyyun 服务器」技能登录，创建独立的 `/tmp/ludo-deploy.*` 临时目录。
3. 只上传 `index.html` 和部署脚本 `py/deploy_static.py` 到临时目录。脚本留在临时目录，公开版本中只写入 HTML。
4. 在服务器执行 `python3 <临时目录>/deploy_static.py <临时目录>/index.html <本地HTML的SHA-256>`。
5. 脚本检查上传摘要，建立版本目录，切换软链接并验证本机 HTTP。验证失败会恢复本次切换前的入口。
6. 用 `node tools/verify-public.cjs output/deploy/public-check.json` 校验公网摘要，再通过浏览器验收，保存输出中的 `previousRelease`，并清理本次临时上传目录。脚本中的 `localHttpVerified` 仅代表服务器本机的 IP 路径验证，不替代外部 HTTPS 验收。

部署不需要把整个项目上传到网站目录。私钥仅用于 SSH 身份认证，不上传到服务器网页目录；项目 `.gitignore` 已排除 `*.pem`。

后续回滚应将 `current` 原子切回已验证的上一版本目录，再检查公网响应摘要。若需要停止公开访问，应同时停用本项目独立域名站点和原 IP 入口，保留版本文件；只移除 IP 入口不会关闭独立域名。
