# 右侧面板一致性验收

日期：2026年09月09日

版本：0.5.7

## 修改内容

开局前的整张面板覆盖图会在开始游戏、切换难度或键盘聚焦时撤掉，露出另一套字体、按钮和骰子。现在桌面端始终使用真实控件，纸纹、边框、玩家标记、计分、装饰线和操作按钮共用同一套样式。

- 恢复计分区分隔线、红色按钮的纹理和内描边、底部重新开始的双线装饰。
- 计分数字继承统一文字颜色，主按钮箭头固定为向右。
- 骰子统一尺寸、圆角、静止位置和阴影。沿用 `dice-roll` 动画名称，游戏仍等待动画结束后公布结果。
- 长标题和操作文案使用较小字号；说明文字、日志使用固定区域，防止挤动骰盘和按钮。
- 禁用按钮保留纹理与描边，仅使用必要的颜色或透明度反馈。
- 构建不再内嵌未使用的完整计分板和静态五点骰子图片。原始素材保留。
